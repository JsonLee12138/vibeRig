# Test Engineering

Create a test contract mapping each acceptance criterion and major risk to an oracle, environment, data/fixture owner, setup, cleanup, and expected evidence.

Choose the lowest test level that proves the behavior, but use integration, contract, E2E, migration, performance, or security tests when unit tests are insufficient. Clearly label simulated evidence and missing real-environment evidence. Writing or running tests does not grant final acceptance.
