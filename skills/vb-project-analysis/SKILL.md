# Project Analysis

Inspect manifests, lockfiles, build scripts, CI, deployment configuration, schemas, migrations, tests, generated code boundaries, feature flags, and module ownership.

Produce:

- languages, frameworks, package/build tools, and exact evidence;
- frontend, backend, data, API, deployment, and trust-boundary topology;
- test levels, commands, environments, fixture ownership, and missing prerequisites;
- path ownership and likely specialist roles;
- confidence, stale assumptions, and knowledge gaps.

Do not infer the deployed architecture from README files alone.
