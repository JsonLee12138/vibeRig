# Security Audit

Trace attacker-controlled input through trust boundaries and privileged actions. Check authentication, authorization, tenant/project binding, injection, SSRF, secrets, logging, supply chain, replay, deletion, and recovery.

Classify findings as Blocking, Notable, or Minor. Security review is probabilistic evidence; deterministic policy and scanners remain separate hard gates.
