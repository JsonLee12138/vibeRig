# Implementation

Verify the assigned scope and acceptance contract before editing. Make the smallest complete change, preserve unrelated user work, run proportional checks, and report:

- files changed and why;
- commands, exit codes, and environment;
- deviations from the approved design;
- residual risks and work requiring another role.

Do not change Plane state or claim final acceptance.
