# Reliability Engineering

Inspect failure domains, startup and shutdown, queues, timeouts, retries, rate limits, data durability, deployment order, rollback, SLI/SLO coverage, backup consistency, restore testing, RPO, and RTO. Distinguish tested recovery from documented intent.
